## 0. 給接手者

### 0.1 這份規格在做什麼

找出「單一分點在某檔股票裡，交易時點能預測之後的股價」的情形，並區分這是真的擇時、自己拉抬、還是機械性的逆勢承接。觸發案例是 2601 益航的富邦-二林，但它在開發集，只能除錯，不能當作方法有效的證據。

### 0.2 實作規則（沿用主力集團 v3 的治理）

1. 參數全部寫進 `params.yaml` 的 `timing:` 區塊，`timing_version: 1.1.2`，在看任何結果之前 commit。修改要記 CHANGELOG，理由不得來自驗證結果。
2. 切分沿用 v3 §2：開發集 D（含 2601）只能除錯；跨股票保留池 H 不寫 Firestore、不顯示；T_cut = 2026-11-04。
3. 規格沒寫清楚的地方，選最簡單、最保守的做法，標 `SPEC-GAP-timing`，寫進程式註解與 CHANGELOG。
4. 每一步都要通過 §11 的驗收測試才合併。
5. 分點資料只限自用（FinMind 授權），網頁只開放給擁有者。

## 1. 要抓什麼

v0 的定義是「低買高賣、賺到錢、反覆發生」。這三個條件都可以由非擇時的機制產生：自己把價格推上去（衝擊）、看到跌就買而股價本來就會反彈（逆勢承接）、跟著大盤或產業進出（市場、產業擇時）、只賣賺錢的部位（處置效應）。v1.1 的定義：

> 分點的跨日交易中，**無法用它對過去價格的反應來解釋的部分**，能預測該股票之後**扣除大盤與產業後的超額報酬**。

分類（判定規則見 §5）：

| 類型 | 意義 | 對主力偵測的價值 |
|---|---|---|
| 擇時／資訊型 | 交易時點本身有預測力，扣除自己後續交易的推升後大部分仍在 | 高：可能有資訊優勢 |
| 拉抬型 | 預測力主要來自自己後續的買進把價格推上去 | 高：典型主力拉抬 |
| 混合型 | 兩者都有，資料無法區分 | 中：人工檢視 |
| 逆勢承接型 | 低買高賣只是「跌就買、漲就賣」碰上均值回歸 | 低：散戶集中或造市性質 |
| 無 | 沒有統計上的擇時現象 | — |

不在範圍內：只買不賣的鎖碼、隔日沖、多分點協同（主力集團 v3 的範圍）。

網頁需註明：分點是許多客戶的合計，顯著只代表「從這個分點下單的資金整體有此現象」，不能直接說是單一主力，也不構成違法認定。

### 3.1 資料與載入期間

|---|---|---|---|

| 大盤報酬指數 | TaiwanStockTotalReturnIndex（上市 TAIEX、上櫃 TPEx） | 2020-11-01 | 超額報酬 |
| 產業別 | TaiwanStockInfo industry_category | — | 產業報酬、安慰劑選股 |
| 公司行動 | v3 §3.2 的 `corp_actions.parquet` | — | 股數基準因子 g_t |
| 分點價位明細（選用） | TaiwanStockTradingDailyReport | 2021-06-30 | 執行成分的價位分布 |
| 人工更正 | 私人倉庫 `corrections.json` | — | 在所有計算之前套用 |
| 交易日曆 | TaiwanStockTradingDate | — | 前瞻期間以交易日計 |

- 價格與指數從 2020-11-01 載入，是為了讓 2021-06-30 起的第一個分點交易日就有 120 日的 β 估計期與 60 日的成交量基準（預熱期）。
- 一個交易日 t 要進入樣本，必須在 t 之前已有至少 120 個有效交易日（C_t > 0）。上市未滿 120 日的股票，那段期間不進樣本。
- 原始收盤價 C_t ≤ 0（無公告價）的日子不用。

### 3.2 金額與報酬的基準

**金額一律用原始價 × 原始股數，報酬一律用還原價。** 當日的台幣金額不受之後的除權息影響；跨日比較價格時才需要還原。

```
當日金額：  n_t · VWAP_t、 (VWAP_t − BP_t) · (b_t − d_t)        （原始價、原始股數）
報酬：      r_t = C^adj_t / C^adj_{t−1} − 1                        （還原價）
```

v1 的 BP^adj、VWAP^adj 作法廢除。

### 3.3 股數基準與標準化

跨期加總或比較股數時（累積淨量、中位數、門檻），先換算成最新股數基準，避免分割、減資、配股前後的股數不可比：

```
k_τ   = 公司行動 τ 的股數因子（v3 §3.2：配股 1 + r；分割、面額變更、減資用 P_before / P_ref；現金股利為 1）
g_t   = Π_{τ > t} k_τ        （t 之後所有公司行動的股數因子連乘；最新一日 g = 1）
n^cb_t = g_t · n_t
ñ_t   = n^cb_t / median{ |n^cb_τ| : τ 為活躍日 }
```

- 現金減資的 k 是近似值（v3 §3.2），該事件標 `ca_approx`；跨越這類事件的循環數在報告中加註。
- 分點類型（proprietary、foreign、gov_bank、brokerage）沿用 v3 §4.1，照常檢定，報告分開列。
- 隔日沖型分點照常檢定，報告加註。

### 3.4 雙因子超額報酬

```
r^stk_{t→t+h} = C^adj_{t+h} / C^adj_t − 1
r^mkt_{t→t+h} = M_{t+h} / M_t − 1
r^ind_{t→t+h} = 同產業其他股票 r^stk_{t→t+h} 的等權平均（排除 j 本身）
r^ex_{t→t+h}  = r^stk_{t→t+h} − β^m_t · r^mkt_{t→t+h} − β^ind_t · (r^ind_{t→t+h} − r^mkt_{t→t+h})
```

- (β^m_t, β^ind_t) 用 [t−120, t−1] 的日報酬做 OLS：r_j = α + β^m r^mkt + β^ind (r^ind − r^mkt)。只用 t 以前的資料。
- 產業以 TaiwanStockInfo 的 industry_category 為準，產業成員取 v3 §2.3 的股票宇宙。同產業其他股票少於 5 檔時，去掉產業項，只扣大盤，並在輸出中標 `industry_factor = false`。
- 前瞻報酬從 **t 日收盤**起算，當日自身衝擊已反映在 C_t。
- **預先計算**：β̂^m_t、β̂^ind_t 與 r^ex_{t→t+h}（h ∈ {5, 10, 20, 40}）只依賴股票 j 與交易日 t，與分點無關。實作時在「股票 × 交易日」層級一次算好存檔，分點迴圈只讀取，不得在迴圈內重複做 120 日滾動 OLS。

## 4. 主檢定的數學模型

每個「股票 j × 分點 i」在一個期間只做一次主檢定。調參集期間：2021-06-30 至 T_cut。

### 4.1 樣本

- 樣本 = 股票 j 在期間內的交易日 t，滿足：t 之前已有 120 個有效交易日（§3.1），且 t ≤ T − 40（T 為期間最後一個交易日）。
- **四個 h 一律使用同一個樣本**（截在 T − 40），確保跨期間的相關矩陣有意義。
- **兩階段的樣本範圍不同**：第一階段（§4.2 反應函數與殘差）使用到最後一日 T 的所有活躍日，殘差 ε̂_t 也計算到 T；只有第二階段（§4.3 檢定迴歸、§4.5 EI）的應變數樣本截在 t ≤ T − 40。這樣 §4.5 在 t = T − 40 時仍有完整的 [T−39, T] 殘差可用。第一階段不使用任何前瞻報酬，用到 T 沒有前視問題。
- 非活躍日的交易變數記為 0，讓前瞻報酬的重疊結構在交易日上是規則的。

### 4.2 反應函數與殘差

只在活躍日上估計：

```
ñ_t = μ + φᵀ x_t + ε_t

x_t = std[ min(r_t, 0),
           r_{t−1},
           Σ_{τ=t−5}^{t−1} r_τ,
           Σ_{τ=t−20}^{t−1} r_τ,
           pos20_{t−1},
           log( (V_{t−1} + 1) / (Ṽ_{t−1} + 1) ),
           min(r^mkt_t, 0) ]

pos20_{t−1} = (C^adj_{t−1} − L20) / (H20 − L20)，L20、H20 為 [t−20, t−1] 的還原收盤價最低、最高值；H20 = L20 時取 0.5
Ṽ_{t−1}     = [t−61, t−2] 的成交量中位數
```

- **當日只保留下跌的部分**：min(r_t, 0) 與 min(r^mkt_t, 0) 吸收「跌的那天買」的單日逆勢；當日上漲的部分不放進反應函數，避免把「看到利多盤中進場、當天已先漲」的資訊型買盤當成追價洗掉。
- 成交量改用前一日（V_{t−1}），不用當日成交量，理由同上。
- pos20 只用還原收盤價，不用盤中高低價，讓它恆在 [0, 1] 之間，也讓 §9.2 的注入只需調整收盤價。
- **目標函數**（明定，避免懲罰強度隨樣本數變化）：

```
min over (μ, φ):  (1 / N_act) Σ_{活躍日} (ñ_t − μ − φᵀx_t)² + λ ‖φ‖²，  λ = 0.01，μ 不懲罰
```

  - x_t 在活躍日上標準化（平均 0、標準差 1）。
  - 用 scikit-learn 的 `Ridge` 時，`alpha = λ · N_act`（因為它的目標函數沒有除以樣本數）。
- 反應函數在到最後一日 T 的所有活躍日上估計，ε̂_t 也計算到 T（§4.1）。
- 非活躍日的 ε̂_t 記為 0。由於截距不懲罰，活躍日的 ε̂ 總和為 0，所以第二階段的斜率只由活躍日決定。

### 4.3 檢定迴歸

對每個 h ∈ {5, 10, 20, 40}，在 §4.1 的同一個樣本上：

```
r^ex_{t→t+h} = a_h + θ_h · ε̂_t + u_{t,h}
H₀: θ_h = 0     H₁: θ_h > 0（單尾：之後漲的時候它在買）
```

### 4.4 標準誤、多期間合併與小樣本自由度

**堆疊式 Newey–West**（取代 v1 的循環平移相關矩陣）。四個 θ̂_h 的聯合共變異數直接解析計算：

```
x_t      = ε̂_t − mean(ε̂)                    （全樣本中心化）
ψ_t      = ( x_t · û_{t,5}, x_t · û_{t,10}, x_t · û_{t,20}, x_t · û_{t,40} )ᵀ
Γ_ℓ      = (1/T) Σ_{t=ℓ+1}^{T} ψ_t ψ_{t−ℓ}ᵀ
Ω        = Γ_0 + Σ_{ℓ=1}^{L} (1 − ℓ/(L+1)) (Γ_ℓ + Γ_ℓᵀ)，   L = 40
V        = T · Ω / (Σ_t x_t²)²
se_h     = √V_hh，  t_h = θ̂_h / se_h
R        = V 轉成的相關矩陣
```

- 單一延遲 L = 40（等於最長前瞻期間），四個 t_h 與 R 都由同一個 Ω 算出，彼此一致。
- 不再需要任何平移，短樣本（時間保留期、新上市股票）也能計算。

**有效區塊數與小樣本自由度**。活躍日集中在少數波段時，Newey–West 在小樣本下低估標準誤。用有效區塊數當自由度，讓 p 值反映真正的資訊量：

```
G_eff = 從樣本第一日起，把樣本切成不重疊的 20 交易日區塊（最後不足 20 日的也算一塊）後，含有至少一個活躍日的區塊數
df    = G_eff − 1
```

**多期間合併**（Cheverud–Nyholt 有效檢定數，完全確定、尾端精確）：

```
T_max    = max_h t_h
p_min    = P( t_df > T_max )                                    （單變量 t 尾機率：scipy.stats.t.sf(T_max, df)）
λ_1..λ_4 = R 的特徵值
M_eff    = 4 − (1/4) · Σ_k (λ_k − 1)²                          （= 1 + 3 · (1 − Var(λ)/4)，Var 以 4 − 1 為分母；介於 1 與 4）
p^E      = min(1, M_eff · p_min)
```

- 為什麼不用四維 t 分布的 CDF（v1.1 的作法）：SciPy 的 `multivariate_t.cdf` 以隨機化 QMC 積分。不固定種子就無法重現；更根本的是，p = 1 − F 在 p 很小時，QMC 的絕對誤差會蓋過 p 本身，而 BH 需要的正是準確的小 p。上式不含任何隨機性，尾端精確，代價是比精確的聯合分布略為保守（最多 M_eff 倍）。
- M_eff 由 R 決定，隨相關性連續變化：λ = (4, 0, 0, 0)（完全相關）時為 1，λ = (1, 1, 1, 1)（完全獨立）時為 4。
- 為什麼不用 Li–Ji（v1.1.1 的作法）：4 × 4 相關矩陣的特徵值總和恆為 4，所以 Li–Ji 公式的小數部分加總恆為整數，M_eff 只會是整數，在 λ₁ = 3 處跳動，四個期間幾乎完全相關（λ₁ = 3.999）時仍是 2 而不是接近 1。
- 數值保護：特徵值先截在 [0, 4]（最近正定矩陣之後仍可能有 −1e-12 這類誤差），M_eff 再截在 [1, 4]。
- M_eff · p_min 是 Bonferroni 型校正，是否過度保守或不足，由 §9.1 的安慰劑校正檢查。
- R 不是正定時，先取最近的正定矩陣再算特徵值。
- p 截在 [1e-15, 1]。
- 最強期間 h* = argmax_h t_h，供 §4.5 與報告使用。

### 4.5 分類用的附加檢定

**原始版（R）**：把 ε̂_t 換成 ñ_t（不扣反應函數），其餘同 §4.3、§4.4，得到 p^R。

**當日追價版（E+）**：反應函數的 x_t 再加入 max(r_t, 0)，其餘同主檢定，得到 p^{E+}。只用於旗標（§5）。

**控制自身後續交易版（EI）**，鎖定在主檢定的最強期間 h*：

```
F⁺_{t} = Σ_{τ=t+1}^{t+h*} max(ε̂_τ, 0)        （之後自己「超出平常反應」的買進）
F⁻_{t} = Σ_{τ=t+1}^{t+h*} min(ε̂_τ, 0)        （之後自己「超出平常反應」的賣出）

r^ex_{t→t+h*} = a + θ^EI · ε̂_t + κ⁺ · F⁺_t + κ⁻ · F⁻_t + u_t
```

- **用殘差 ε̂ 而不是原始 ñ**：原始淨量會對期間內的價格變化做出反應（例如漲了就停利），使 F 與誤差項相關。殘差已扣除對價格的反應，同時性偏誤小得多。
- **拆成正、負兩部分**：先拉後倒時，前段大買、後段大賣，淨量總和會互相抵銷而接近 0。拆開後，拉抬的買進由 F⁺ 吸收、出貨由 F⁻ 吸收。
- **判定統計量：線性差值**（不用比值，避免分母接近 0）：

```
Δ = θ̂^EI − 0.5 · θ̂^E_{h*}        （θ̂^E_{h*} 為主檢定在 h* 的斜率）
ρ = θ̂^EI / θ̂^E_{h*}              （只供顯示）
```

- **信賴區間**：移動區塊 bootstrap。把樣本日 t 的整列 (r^ex_{t→t+h*}, ε̂_t, F⁺_t, F⁻_t) 以長度 40 的區塊重抽，B = 999 次，每次同時重估 θ̂^E*_{h*} 與 θ̂^EI*，算 Δ* = θ̂^EI* − 0.5 · θ̂^E*_{h*}，取 5% 與 95% 分位數為 [Δ_lo, Δ_hi]。亂數種子 = hash(stock, branch, "EI")，固定。
- **退化重抽的處理**：
  - 重抽樣本的 Σ(ε̂*_t − mean ε̂*)² = 0（全部抽到非活躍區塊）時，θ̂^E* 沒有定義，該次剔除，**不補抽**（補抽會讓結果依賴額外的亂數序列）。
  - EI 迴歸用最小範數最小平方法（`np.linalg.lstsq(X, y, rcond=None)`）。F⁺ 或 F⁻ 整欄為 0 時，對應係數退化為 0，θ̂^EI* 照常估計，不拋出例外。
  - 記錄剔除比例。剔除比例 > 10% 時，信賴區間視為不可靠：不歸為類型 1 或 2，改歸混合型，並在報告中標「bootstrap 不穩定」。
  - 分位數只在保留下來的重抽上計算。
- **為什麼用差值**：稀疏分點重抽時，θ̂^E* 可能接近 0 或為負，比值會爆到 ±10⁶，分子分母同為負時還會「負負得正」。Δ 沒有分母。在 θ̂^E > 0 時，「Δ ≥ 0」與「ρ ≥ 0.5」是同一個假設；兩者的 bootstrap 分位數不完全相同，但 Δ 的抽樣分布行為良好，是較可靠的檢定。
- **顯示用的 ρ 區間**：只用 θ̂^E*_{h*} > 0 的重抽計算 ρ* 的 5%、95% 分位數，並報告剔除比例；剔除比例 > 10% 時標「不穩定」。ρ 不參與分類。
- EI 是事後分解，用到 t 之後的資料是刻意的（回答「效果是不是靠自己後續交易推出來的」），不是預測模型，沒有前視問題。

## 5. 分類規則

顯著與否只由主檢定 E 與原始版 R 各自的 BH 決定（§7）。EI 與 E+ 只用於已顯著者的分類與旗標，不產生新的發現。

| 順序 | 條件 | 類型 |
|---|---|---|
| 1 | q^E ≤ 0.05 且 Δ_lo ≥ 0 | 擇時／資訊型 |
| 2 | q^E ≤ 0.05 且 Δ_hi ≤ 0 且 κ̂⁺ > 0 | 拉抬型 |
| 3 | q^E ≤ 0.05，不符合 1、2 | 混合型 |
| 4 | q^E > 0.05 且 q^R ≤ 0.05 | 逆勢承接型 |
| 5 | 其他 | 無 |

- 門檻 0.5 的意思：扣除自己後續交易的影響後，至少（擇時型）或至多（拉抬型）還剩一半的效果。用信賴區間的上下界判定，避免 v1「q 值對未校正 p 值」的不對稱：一個 t 值從 4.5 降到 2.3 的分點，ρ 約 0.5，Δ 的信賴區間會跨過 0，被歸為混合型，而不是擇時型。
- 拉抬型另外要求 κ̂⁺ > 0：自己之後的買進確實伴隨更高的報酬。
- **當日追價旗標**：類型 1～3 中，若 p^{E+} > 0.05，加註「顯著性依賴當日上漲時的買進：可能是資訊型，也可能是當日追價碰上短期動能」。
- 報告顯示 p^E、q^E、p^R、q^R、Δ 與信賴區間、ρ（顯示用）、κ̂⁺、p^{E+}，讓使用者看得到判斷依據。

## 6. 門檻與波段計數

門檻只用分點自己的交易與成交量決定，不看前瞻報酬，所以不會讓檢定偏向「看起來有擇時」的分點。

### 6.1 進入檢定的門檻

一個「股票 × 分點」同時符合以下條件才進入檢定：

1. 活躍日 ≥ 40 天。
2. 有效區塊數 G_eff ≥ 8（§4.4）。
3. Zigzag 波段計數的完整循環數 ≥ 3（§6.2）。
4. 期間內跨日交易量合計 ≥ 該股票同期成交量的 0.5%。

### 6.2 Zigzag 波段計數（取代 v1 的分位數遲滯門檻）

v1 用全期間累積淨量的第 25、75 百分位當門檻，有三個問題：只在其中一年操作的分點，八成日子累積淨量為 0，兩個門檻都是 0；每波留下底倉的分點，累積淨量呈階梯上升，前期碰不到上門檻、後期回不到下門檻；首尾方向不同時少算。v1.1 改用 zigzag：只要累積淨量從上一個極值反向移動超過振幅門檻 A，就確認一段波段。

```
I_t = Σ_{τ≤t} n^cb_τ                          （最新股數基準的累積跨日淨量，期初為 0）
P̄   = 活躍日的 C_t / g_t 中位數                （最新股數基準下的典型價格）
A   = max( 5,000,000 元 / P̄,  5 · median{ |n^cb_t| : 活躍日 } )      （股，最新股數基準）
```

演算法（只走活躍日，非活躍期間 I 不變、不產生波段）：

1. 起點設在第一個活躍日**之前**：hi = lo = 0（期初累積淨量），方向未定。這樣第一個活躍日的交易也會計入波段。
2. 方向未定時，每走過一個活躍日，先更新 hi = max(hi, I_t)、lo = min(lo, I_t)，再判斷：
   - hi − I_t ≥ A：確認第一段向下（段數 = 1），極值 = I_t。
   - 否則若 I_t − lo ≥ A：確認第一段向上（段數 = 1），極值 = I_t。
   - 這樣「先小跌、再大漲」的情形，只要從區間低點起漲超過 A 就會確認。
3. 方向為上：I_t 創新高就更新極值；I_t ≤ 極值 − A 時確認反轉，段數 + 1，方向改為下，極值 = I_t。
4. 方向為下：對稱處理。
5. 完整循環數 = ⌊ 確認的段數 / 2 ⌋。

- **振幅門檻用金額**（500 萬元換算成股數），不會系統性排除高價股，也避免低價股的雜訊。
- 只在其中一年操作的分點：非活躍期間不產生波段，操作期間的每一段照常計算。
- 留底倉的分點：每波買 1,000 張、賣 700 張，只要 700 張超過 A，每一波都被計入。
- 首段方向向上或向下都可以，沒有方向不對稱。
- 完整循環數 3～4 的分點在報告中標「樣本偏少」。

### 6.3 期初庫存

I_t 只用來數波段，不代表真實持股。描述用的真實持股與成本（§8）沿用 v3 §3.3 的分批庫存：已知成本批 L、未知成本批 U、疑似空頭批 S；U 批不計入損益。

## 9. 驗證

§9.1、§9.2 是方法診斷，可以據以修方法（同一項最多三輪，每輪記錄）；§9.3 是案例說明，不得據以改參數。全部只在調參集上跑。

### 9.1 安慰劑股票校正

把分點在股票 j 的交易序列，配上**不同產業**的另一檔股票 j′ 的價格。這保留分點自己的交易習慣與大盤共同走勢，拿掉個股與產業層級的擇時，所以 p 值在虛無下應該均勻。

- j′ 的選法：industry_category 與 j 不同、不在 H、不在 D；以 log 市值、log 日均成交值、β^m 三者標準化後的歐氏距離最近者。
- 反應函數特徵、超額報酬（含 j′ 自己的產業項）都用 j′ 的資料重算；分點的 ñ_t 不變。
- 判準（單邊 super-uniform）：

```
F̂(α) = #{ p^E_placebo ≤ α } / N  ≤  1.2 α + 2 √( α(1−α) / N )，   α ∈ {0.001, 0.01, 0.05}
```

- **分層檢查**：依 G_eff（8～11、12～19、≥ 20）與活躍日數（40～79、80～159、≥ 160）分層，每層各自檢查。小樣本層不通過時，表示 §4.4 的自由度修正不夠，要修方法。
- p^R 也做同樣檢查。
- 另外報告安慰劑資料做 BH 後的發現數；應接近 0。

### 9.2 合成注入（含平方根價格衝擊）

宿主：調參集中 p^E > 0.5 的「股票 × 分點」。

**價格衝擊模型**（注入日 t 的淨量 Δ_t，從 t 日收盤起永久生效）：

```
log C^adj_τ ← log C^adj_τ + 0.5 · sign(Δ_t) · σ_t · √( |Δ_t| / ADV_t )，   對所有 τ ≥ t
σ_t   = [t−20, t−1] 的日報酬標準差
ADV_t = [t−60, t−1] 的平均成交量
```

（平方根衝擊法則，係數 1，其中一半為永久衝擊。）

§4.2 的 pos20 只用還原收盤價，所以注入時只需調整還原收盤價。若實作中有其他特徵用到開、高、低價，同一衝擊必須同步加到所有 τ ≥ t 的還原開、高、低、收。

**注入組**：

| 組別 | 方式 | 預期 |
|---|---|---|
| 擇時 | 每天以機率 π 交易；方向以機率 ψ 與未來 20 日超額報酬同號 | 擇時型或混合型 |
| 純衝擊 | 隨機方向的多日同向段落（每段 5～15 天），加衝擊 | 拉抬型、混合型或無；**不得**是擇時型 |
| 先拉後倒 | 5 天買進段落後接 10 天賣出段落，加衝擊 | 拉抬型、混合型或無；**不得**是擇時型 |
| 逆勢 | 前 5 日累積報酬為負時買、為正時賣，加衝擊 | 逆勢承接型或無；**不得**是擇時或拉抬型 |

- 注入量：|Δ_t| = φ · ADV_t，φ ∈ {0.02, 0.05}；π ∈ {0.1, 0.3}；ψ ∈ {0.55, 0.6, 0.7}。
- **混淆率的分母只算已顯著者**：
  - 純衝擊、先拉後倒：在 q^E ≤ 0.05 的樣本中，被判為擇時型的比例 ≤ 10%。
  - 逆勢：在 q^R ≤ 0.05 的樣本中，被判為擇時型或拉抬型的比例 ≤ 10%。
- 已顯著樣本少於 20 個時，該組結果標「測試無效」，改用 φ = 0.05 加跑；仍不足則記錄，不判通過。
- 擇時組報告偵測率（檢定力）與分類分布。
- 只用來判斷偵測得到與否、找 bug，不用來調門檻。

## 12. 對 v1 審查意見的回覆

### 12.1 接受並照建議修正

- 遲滯循環的零值膨脹、長期底倉、方向不對稱：三點都成立。修正方式比建議更進一步，直接改成 zigzag，不需要決定「活躍區間」或「去趨勢」的細節（§6.2）。
- EI 的門檻不對稱、F 正負相抵、同時性偏誤、未鎖定 h*：四點都成立，照建議改為衰減比例 + 鎖定 h* + 拆正負 + 用殘差（§4.5、§5）。
- 還原價乘原始股數、股數跨公司行動不可比、Ridge 懲罰尺度、振幅門檻偏向高價股、預熱期、除零、樣本尾端不一致：全部成立，照建議修正。
- 安慰劑的產業混淆：成立。同時採用兩個建議：超額報酬扣除產業報酬（§3.4），安慰劑改選不同產業（§9.1）。
- 注入的衝擊太小與分母未條件化：成立。衝擊改用平方根法則，注入量以成交量比例設定，分母改為已顯著者（§9.2）。

### 12.2 接受問題、但修正方式不同

- **多期間相關矩陣**：審查提出兩個選項（解析計算，或把平移保護帶改成 max(40, ⌊0.1N⌋)）。採用解析計算，完全不再使用循環平移，因為保護帶的作法在短樣本仍然解析度不足。
- **稀疏樣本的 HAC 低估**：問題成立。審查未給具體修正；本版用「自由度 = 有效區塊數 − 1」的 t 分布，加上 G_eff ≥ 8 的門檻，並在安慰劑校正中依 G_eff 與活躍日數分層檢查。若分層校正不通過，下一輪改用 fixed-b（Kiefer–Vogelsang）臨界值。
- **方向不對稱**：v1 的累積淨量期初為 0，期初庫存本身不會造成問題；但首段向下時確實少算一次。zigzag 一併解決。

### 12.3 延伸問題的答覆

1. **EI 重構**：採用拆正負（F⁺、F⁻）而非前後半段，因為前後半段的切點是任意的，拆正負直接對應「拉抬的買」與「出貨的賣」。衰減判定搭配移動區塊 bootstrap 信賴區間（v1.1.1 起改用線性差值 Δ，見 §12.4；退化重抽規則見 §12.5），新增「混合型」承接無法區分的情況（§4.5、§5）。
2. **反應函數的當日資訊洩漏**：成立。當日報酬改為鉸鏈 min(r_t, 0)，成交量改用前一日。代價是「當日追價碰上短期動能」可能被當成擇時，因此另跑 E+ 版本，顯著性依賴當日上漲買進時加註旗標（§4.2、§5）。
3. **遲滯循環與活躍區間**：改用 zigzag，同時處理短期戰役型與長線底倉型分點，不需要另外定義分位數母體或去趨勢（§6.2）。


### 12.4 對 v1.1 實作邊界審查的回覆

1. **Zigzag 起點**：兩個問題都成立，照建議修正（§6.2）。驗收測試新增「首日建倉後清空」與「先小跌後大漲」兩個案例（§11 步驟 2）。
2. **EI 尾端截斷**：成立，照建議修正：第一階段算到 T，第二階段截在 T − 40（§4.1、§4.2）。
3. **Bootstrap 比值爆炸**：成立，照建議改用 Δ = θ^EI − 0.5 θ^E。補充：在 θ^E > 0 時，「Δ ≥ 0」與「ρ ≥ 0.5」是同一個假設，但兩者的 bootstrap 分位數並不代數等價；Δ 的好處是抽樣分布行為良好，不只是換個寫法（§4.5）。
4. **multivariate_t.cdf 的隨機性**：問題成立，但固定種子只解決可重現性。更根本的是 p = 1 − F 在 p 很小時，QMC 的絕對誤差會蓋過 p 本身，而 BH 需要的正是準確的小 p。因此改為完全不用 QMC：以最大 t 值的單變量 t 尾機率乘以有效檢定數（§4.4；v1.1.2 起由 Li–Ji 改為 Cheverud–Nyholt，見 §12.5）。結果完全確定、尾端精確，代價是略為保守，由 §9.1 的安慰劑校正檢查。
5. **注入的 pos20**：成立，採用較簡單的作法：pos20 改用還原收盤價的 20 日高低（§4.2）；若其他特徵用到開高低價，衝擊要同步加上（§9.2）。


### 12.5 對 v1.1.1 最終審查的回覆

1. **M_eff 的整數性**：成立，而且是 v1.1.1 引入的錯誤。相關矩陣的特徵值總和恆為 4，Li–Ji 的小數部分加總恆為整數，所以 M_eff 只有整數值，在完全相關時也降不到 1。改用 Cheverud–Nyholt（§4.4）。這改變 p 值，屬於方法修改，因此寫進規格與 CHANGELOG，而不是只當作程式註解。
2. **Bootstrap 退化**：成立。照建議剔除全零重抽、用最小範數最小平方法；另外補一條：剔除的重抽不補抽（避免結果依賴額外亂數），剔除比例 > 10% 時改歸混合型（§4.5）。
3. **超額報酬預計算**：成立，屬於實作效率，寫進 §3.4 讓實作者照做。
4. **凍結**：同意。v1.1.2 為凍結版；之後若驗收測試或診斷要求修改，依 §0.2 寫 CHANGELOG 並註明條目，不再另發規格。

## 13. 對 v0 第 10 節六個問題的答覆（更新版）

1. **整段循環平移或交易段落重排？** 兩者都不當主檢定。主檢定用堆疊式 Newey–West 加小樣本自由度（§4.4）；校正用不同產業的安慰劑股票（§9.1）。
2. **怎麼控制逆勢承接？** 反應函數殘差（§4.2），當日只保留下跌部分；分類見 §5 第 4 類。
3. **k 怎麼選？** 不只選一個。四個前瞻期間的最大 t 值，以 Cheverud–Nyholt 有效檢定數校正（§4.4）；位置分數 T 只做描述。
4. **T 與 R 用 Cauchy 合併？** 不建議。兩者幾乎測同一件事，且 R 有處置效應偏誤。只用一個主統計量（§4）。
5. **循環怎麼客觀切分？** Zigzag 波段計數，振幅門檻用金額（§6.2）。
6. **要不要和主力集團 v3 合併？** 可以把擇時型、拉抬型、混合型分點當 v3 的核心候選，但必須樣本切分：前半期間選分點，後半期間檢定同步關係。具體做法另立規格條目，不在本版範圍內。
